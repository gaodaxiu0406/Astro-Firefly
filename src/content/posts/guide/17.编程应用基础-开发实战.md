## 人工智能第十七章 课程练习题（含答案解析）

### 一、单选题

**1.** YOLO11 模型是在哪一年发布的？

- A. 2015 年
- B. 2018 年
- C. 2020 年
- D. 2024 年

**答案：** D

**解析：** YOLO 模型从 2015 年诞生，后续不断迭代发展到 2024 年发布 YOLO11。

**2.** YOLO11 在目标检测中的主要优势是什么？

- A. 模型体积最小
- B. 推理速度快、精度高、小物体检测能力强
- C. 训练数据需求最少
- D. 仅适用于自然语言处理

**答案：** B

**解析：** YOLO11 推理速度很快，平均精度在数据集中显著提高，对小物体检测能力也非常强，且具备良好的泛化能力。

**3.** 在自动驾驶领域，YOLO11 主要用于什么？

- A. 语音识别
- B. 路径规划算法
- C. 实时感知环境，检测车辆、行人和交通标志
- D. 燃料消耗优化

**答案：** C

**解析：** YOLO11 在自动驾驶领域用于实时感知周围环境，检测车辆、行人和交通标志等目标物体。

**4.** 课程中搭建 YOLO11 环境使用的是什么工具？

- A. Docker
- B. Anaconda
- C. VirtualBox
- D. VMware

**答案：** B

**解析：** 课程中使用 Anaconda 搭建 PyTorch 环境，创建名为 yolo11 的 conda 环境。

**5.** 课程中创建的 Python 环境使用的是哪个版本？

- A. Python 2.7
- B. Python 3.8
- C. Python 3.10
- D. Python 3.11

**答案：** C

**解析：** 课程中搭建的是 Python 3.10 的 PyTorch 环境。

**6.** urllib 库的主要功能是什么？

- A. 图像处理
- B. 从网络上下载文件
- C. 数学计算
- D. 深度学习模型训练

**答案：** B

**解析：** urllib 是标准模块，用于从网络上下载文件，如通过 URL 下载图片到本地。

**7.** OpenCV(CV2)库广泛用于哪个领域？

- A. 自然语言处理
- B. 计算机视觉和图像处理
- C. 数据库管理
- D. 网络通信

**答案：** B

**解析：** CV2(OpenCV)是计算机视觉和机器学习常用的库，广泛用于图像处理、视频处理、特征检测和图像分割等。

**8.** Ultralytics(YOLO)库主要用于什么？

- A. 数据可视化
- B. 目标检测模型
- C. 网页开发
- D. 音频处理

**答案：** B

**解析：** Ultralytics 是 YOLO 的检测模型库，用于目标检测，实时检测，广泛用在视觉系统中包括监控抓取人像等。

**9.** NumPy 库的主要用途是什么？

- A. 网页爬虫
- B. 科学计算和多维数组处理
- C. 图形界面开发
- D. 数据库操作

**答案：** B

**解析：** NumPy 用于科学计算，提供多维数组对象和大量操作数组的工具，主要用于高等数学方面的计算。

**10.** 在人物分割程序中，检测到的人物区域被填充什么颜色？

- A. 红色
- B. 绿色
- C. 白色
- D. 蓝色

**答案：** C

**解析：** 程序将检测到的人物区域填充为白色，其他区域为黑色，实现图像分割效果。

**11.** 背景虚化处理的原理是什么？

- A. 对整张图片进行模糊
- B. 保持人物清晰，仅对背景区域进行高斯模糊
- C. 改变图片颜色
- D. 缩小图片尺寸

**答案：** B

**解析：** 背景虚化通过分割技术将人物和背景分离，人物部分保持不变，背景部分进行高斯模糊处理，突出人物清晰度。

**12.** YOLO11 在医疗影像分析中的作用是什么？

- A. 替代医生诊断
- B. 辅助医生检测 X 光片、CT 扫描中的病变组织和肿瘤
- C. 管理医院信息系统
- D. 开发新药

**答案：** B

**解析：** YOLO11 在医疗影像分析中辅助医生检测 X 光片、CT 扫描图像中的病变组织、肿瘤等异常情况。

**13.** 课程中预测函数首先对图像进行什么操作？

- A. 压缩图像
- B. 将图像放入空列表用于分割
- C. 旋转图像
- D. 转换为灰度图

**答案：** B

**解析：** 预测函数先将预测函数模型化，放入一个空列表用于分割图像，然后逐个区域检测。

**14.** YOLO11 的工业生产应用包括什么？

- A. 产品设计
- B. 检测生产现场的产品缺陷
- C. 员工管理
- D. 供应链优化

**答案：** B

**解析：** 在工业生产中，YOLO11 能够检测生产现场的产品缺陷，用于质量控制。

**15.** 在背景虚化程序中，分割线以外的人物部分如何处理？

- A. 删除
- B. 保持不变
- C. 变为黑白
- D. 放大

**答案：** B

**解析：** 分割线以内的人物部分保持不变，分割线以外的环境部分进行虚化（高斯模糊）

处理。

**16.** 课程中使用的 YOLO 模型从哪里获取？

- A. 自己训练
- B. 官方预训练好的模型
- C. 第三方修改版
- D. 从教材附带获取

**答案：** B

**解析：** 课程中使用的 YOLO 模型是官方预处理训练好的模型，从官方网站下载。

**17.** 程序运行后会生成几个图片文件？

- A. 1 个
- B. 2 个
- C. 3 个
- D. 4 个

**答案：** B

**解析：** 程序运行后会产生两个图片文件：原始图片和处理后的图片。

**18.** YOLO11 基于哪两代发展而来？

- A. YOLOv5 和 YOLOv7
- B. YOLOv8 和 YOLOv10
- C. YOLOv3 和 YOLOv5
- D. YOLOv7 和 YOLOv9

**答案：** B

**解析：** YOLO11 基于第 8 代和第 10 代发展起来，YOLO11 主要是基于 YOLOv8 这一代 Ultralytics 经典模型发展而来，在其基础上完成了效率与精度的升级优化。结合 YOLO 系列的完整迭代脉络，它也承接了 YOLOv10 的部分技术演进思路

**19.** 在农业领域，YOLO11 可以通过什么设备获取数据？

- A. 手机
- B. 遥感卫星和无人机
- C. 显微镜
- D. 温度计

**答案：** B

**解析：** 在农业领域，遥感卫星和无人机可以快速获取大面积的土地数据，结合 YOLO11 进行农作物分析。

**20.** 图像分割技术的核心是什么？

- A. 改变图像大小
- B. 将图像中的不同区域/目标进行分离和标记
- C. 提高图像分辨率

**答案：** B

**解析：** 图像分割技术通过检测识别图像中的目标区域，将其与背景分离并用颜色标记，实现区域分割。

### 三、简答题

**1.** 简述 YOLO11 模型的发展历程及其在目标检测中的核心优势。

**答案：** YOLO 模型 2015 年诞生，经历了 1.0 到 11 的迭代。2.0 优化 1.0 不足，3.0 提升检测精度与速度平衡，4-8 代各有突破。YOLO11 基于第 9 代和第 10 代发展，融合优化架构、强化特征抽取技术和精确训练策略。核心优势包括：推理速度快、平均精度显著提高、小物体检测能力强、良好的泛化能力。

**解析：** 需要掌握 YOLO 的版本演进和 YOLO11 的核心技术特点。

**2.** 描述课程中人物分割程序的完整处理流程。

**答案：** 1) 定义预测函数：加载模型，将图像放入空列表用于分割；2) 逐区域检测，将类型转化为整数；3) 判断检测类型是否对应人（person），若是则转换为整数格式；4)

创建模板，用颜色填充分割区域；5) 从网络下载图片到本地；6) 读取图片、加载模型、调用处理函数分割；7) 与原始图像结合进行可视化并输出。处理后会生成原始图片和分割后图片两个文件。

**解析：** 需要理解从环境搭建到图像分割的完整编程流程。
