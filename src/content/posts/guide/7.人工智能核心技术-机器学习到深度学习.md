## 人工智能第七章 课程练习题（含答案解析）

### 一、单选题

**1.** 下列关于机器学习的描述，哪一项最准确？ （单选题）

- A. 机器学习是一种让计算机按固定规则执行任务的编程方法
- B. 机器学习是人工智能的核心驱动力，让机器能够像人类一样从数据中学习经验，提升自身性能
- C. 机器学习是一种数据库管理技术，用于高效存储和检索数据
- D. 机器学习是让计算机完全取代人类决策的一种技术

**答案：** B

**解析：** 课程明确指出：机器学习是人工智能的核心驱动力，让机器从数据中学习经验，提升性能。

**2.** 课程中以垃圾邮件过滤系统说明机器学习的作用，以下描述正确的是？ （单选题）

- A. 垃圾邮件过滤系统通过人工编写规则来判断是否为垃圾邮件
- B. 垃圾邮件过滤系统通过学习大量邮件数据，精准识别垃圾邮件的特征
- C. 垃圾邮件过滤系统通过关键词匹配来进行过滤
- D. 垃圾邮件过滤系统只能过滤已知发件人的垃圾邮件

**答案：** B

**解析：** 系统通过学习大量邮件数据，精准识别垃圾邮件特征，自动拦截。

**3.** 课程中提到的机器学习应用领域不包括以下哪一项？ （单选题）

- A. 医疗疾病诊断
- B. 金融风险预测与量化投资
- C. 航空航天发动机设计
- D. 智能交通

**答案：** C

**解析：** 课程中提到的应用领域包括医疗、金融、智能交通、电商推荐、工业制造等，航空航天发动机设计未提及。

**4.** 在机器学习数学基础中，向量的定义是什么？ （单选题）

- A. 一个单独的数字，表示样本的大小
- B. 一组有序的数值，用于描述样本的特征
- C. 两个样本之间的差值
- D. 数据集中样本的总数量

**答案：** B

**解析：** 向量是一组有序的数值，每个元素代表样本的一个特征，是机器学习中描述样本的基本方式。

**5.** 在机器学习中，距离的主要作用是衡量什么？ （单选题）

- A. 数据集的规模大小
- B. 算法的运行时间
- C. 两个数据点（向量）之间的相似度
- D. 模型的准确率

**答案：** C

**解析：** 距离衡量两个向量之间的关系，距离越近表示越相似，越远表示差异越大。

**6.** 课程中提到的欧式距离（欧几里得距离）计算的是什么？ （单选题）

- A. 两个向量在空间中的曼哈顿距离
- B. 两个向量在空间中的直线距离
- C. 两个向量之间的夹角余弦值
- D. 两个向量的元素个数之差

**答案：** B

**解析：** 欧式距离计算两个向量在空间中的直线距离。课程以向量 A=[1,2,3]、B=[4,5,6]为例说明。

**7.** 关于监督学习，以下描述正确的是？ （单选题）

- A. 监督学习使用的数据不需要标注标签
- B. 监督学习就像老师指导学生，训练数据需要进行标记
- C. 监督学习只能处理分类问题，不能处理回归问题
- D. 监督学习是效果最难评估的机器学习类型

**答案：** B

**解析：** 监督学习需要标记数据，就像老师指导学生，让计算机知道正确答案。包括分类和回归。

**8.** 监督学习主要包括哪两类任务？ （单选题）

- A. 聚类和关联规则
- B. 分类和回归
- C. 降维和特征提取
- D. 生成和判别

**答案：** B

**解析：** 课程明确：监督学习包括分类（判断类别）和回归（预测连续值）。

**9.** 以下哪个是监督学习中回归任务的典型例子？ （单选题）

- A. 判断一封邮件是否为垃圾邮件
- B. 根据房屋面积和数量预测房价
- C. 将水果按种类自动分组
- D. 发现超市中经常一起购买的商品

**答案：** B

**解析：** 房价预测是典型的回归任务，预测的是连续值。A 是分类，C 和 D 是无监督学习。

**10.** 关于无监督学习，以下描述错误的是？ （单选题）

- A. 无监督学习的数据没有标记标签
- B. 无监督学习的任务包括聚类和关联规则挖掘
- C. 无监督学习效果容易评估，因为有明确的正确答案
- D. 无监督学习的数据输出值是未知的

**答案：** C

**解析：** 无监督学习没有正确答案，效果比较难评估。C 错误。

**11.** 无监督学习中的聚类是什么意思？ （单选题）

- A. 将带有标签的数据按类别分开
- B. 根据数据特征将相似的数据自动分成不同小组
- C. 预测连续的目标数值
- D. 在数据中搜索特定的关键词

**答案：** B

**解析：** 聚类是根据特征自动分组，课程以未标注种类的水果自动分组为例说明。

**12.** 无监督学习的关联规则分析常用于什么场景？ （单选题）

- A. 人脸识别
- B. 语音转文字
- C. 超市购物篮分析——发现经常一起购买的商品
- D. 自动驾驶

**答案：** C

**解析：** 课程以超市购物数据为例：发现哪些商品常被一起购买，为营销策略提供参考。

**13.** 关于迁移学习，最准确的理解是？ （单选题）

- A. 将数据从一台计算机迁移到另一台
- B. 利用已学知识快速适应新领域，减少训练时间和数据量
- C. 让模型完全遗忘旧知识，从头学习
- D. 将多个小模型合并成一个大模型

**答案：** B

**解析：** 迁移学习侧重知识迁移，利用已有知识帮助学习新任务，可大大减少训练时间和数据量。

**14.** 强化学习中，智能体的目标是什么？ （单选题）

- A. 尽可能快地完成所有动作
- B. 通过与环境交互，调整策略使累积奖励最大化
- C. 收集尽可能多的训练数据
- D. 模仿人类的所有行为

**答案：** B

**解析：** 智能体根据环境选择行动，环境给出奖励反馈，目标是调整策略使累积奖励最大化。

**15.** 迁移学习和强化学习的主要区别是什么？ （单选题）

- A. 迁移学习侧重知识迁移复用，强化学习侧重环境交互与试错优化
- B. 迁移学习只能处理图像，强化学习只能处理文本
- C. 两者没有本质区别，只是名称不同
- D. 迁移学习需要更多数据，强化学习不需要任何数据

**答案：** A

**解析：** 课程明确对比：迁移学习重知识迁移，强化学习重交互试错、优化行为策略。

**16.** 关于线性回归算法，以下描述错误的是？ （单选题）

- A. 线性回归是一种预测连续值的算法
- B. 原理是找到一条直线来最好地拟合数据点
- C. 线性回归主要用于分类问题
- D. 线性回归优点包括简单易懂、计算效率高、解释性强

**答案：** C

**解析：** 线性回归用于回归（预测连续值），不是分类问题。C 错误。

**17.** 支持向量机（SVM）引入核函数的主要目的是什么？ （单选题）

- A. 加快模型的计算速度
- B. 将低维线性不可分数据映射到高维空间使其线性可分
- C. 减少模型占用的内存
- D. 自动生成更多训练数据

**答案：** B

**解析：** 核函数将低维数据映射到高维空间，使原本线性不可分的数据在高维空间中变得线性可分。

**18.** 关于决策树算法，以下描述正确的是？ （单选题）

- A. 决策树结构类似流程图，每个内部节点表示一个特征的判断条件
- B. 决策树只能处理分类问题
- C. 决策树要求数据必须完整无缺失
- D. 决策树只适用于两个特征的数据集

**答案：** A

**19.** K 近邻（KNN）算法中，新数据点类别的决定依据是什么？ （单选题）

- A. 随机选择一个类别

- C. 始终选择数据集中出现最多的类别
- D. 根据数据点创建时间决定

**答案：** B

**解析：** KNN 在数据集中找到最近的 K 个邻居，按类别投票决定新数据点的类别。

**20.** 关于 K 均值（K-means）聚类算法，以下描述正确的是？ （单选题）

- A. 是一种监督学习算法
- B. K 值不需要预先指定，算法会自动确定
- C. 通过不断更新质心位置来优化聚类结果

**解析：** K-means 是无监督学习，需预先指定 K 值，对初始质心敏感。通过迭代更新质心优化聚类。

### 三、简答题

**1.** 请简述监督学习和无监督学习的主要区别，并各举一个实际应用的例子。

答：主要区别：（1）数据标注：监督学习的数据带有标签（已标记正确答案），无监督学习的数据没有标签。（2）学习目标：监督学习学习输入→输出的映射关系（分类/回归），无监督学习挖掘数据内在结构和模式（聚类/关联规则）。（3）评估难度：监督学习有正确答案，易于评估；无监督学习无标准答案，评估较困难。应用举例：- 监督学习：垃圾邮件过滤（分类）、房价预测（回归）- 无监督学习：客户分群（聚类）、超市购物篮分析（关联规则）

**2.** 请简述迁移学习和强化学习各自的核心特点，并说明它们的主要区别。

答：迁移学习核心特点：侧重知识迁移，利用已有领域学到的知识快速适应新领域，可大大减少训练时间和数据量。强化学习核心特点：智能体通过与环境的交互不断尝试，环境给出奖励/惩罚反馈，目标是调整策略使累积奖励最大化。主要区别：迁移学习重在知识复用和适应；强化学习重在与环境的动态交互和试错优化。
