如果你需要管理Python版本，可以安装uv，uv是Python包管理器。但现在Python自带pip包管理，所以uv现在基本不用了，但既然提到了uv就简单的介绍一下。

## 1. Windows 怎么装

### 1-1‌ 打开 PowerShell‌

在开始菜单搜索 `PowerShell`，右键选择“以管理员身份运行”。

### 1-2‌ 执行安装命令‌：复制粘贴以下命令并回车

```js
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 1-3 重启终端‌

安装完成后关闭并重新打开 `PowerShell`，让环境变量生效。‌‌‌

## 2. Mac 或 Linux 怎么装

### 2-1‌ 打开终端‌

进入系统自带的 `Terminal` 或 `Shell` 窗口

### 2-2‌ 执行安装命令‌

复制粘贴以下命令并回车

```js
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2-3‌ 重启终端‌

同样需要关闭再打开终端，确保命令能被识别。‌‌‌

## 3. 检查装好了没

‌验证命令‌：在终端输入 `uv --version` 或 `uv -V`。

‌成功标志‌：如果能看到版本号（如 `uv 0.x.x`），说明安装成功，可以开始使用了。‌‌‌

常用命令

```js
// 查询已安装的Python版本
uv python list
// 通过uv安装固定Python版本
uv python install 3.13.16
// 指定使用Python版本
uv python listuv python pin 3.13.16
```

## 4. mac卸载uv

### 方法一：使用官方自卸载命令（推荐）

如果你是通过官方脚本 (curl ... | sh) 安装的较新版本（v0.5.2+），`uv` 内置了自卸载功能，这是最干净、最安全的方式。

在终端中运行：

```js
uv self uninstall
```

### 方法二：通过 Homebrew 卸载

如果你是通过 `Homebrew` 安装的，请使用以下命令：

```js
brew uninstall uv
```

### 方法三：手动彻底卸载（适用于所有情况）

如果上述方法无效，或者你想确保没有任何残留文件，可以手动删除相关文件和目录。此过程分为三步：‌删除二进制文件‌、‌清理数据与缓存‌、‌清理环境变量‌。

#### 1. 删除二进制可执行文件

根据安装版本不同，`uv` 可能位于 `~/.local/bin/` 或 `~/.cargo/bin/`。

‌对于 `v0.5.2` 及更高版本（默认路径）：

```js
rm ~/.local/bin/uv
rm ~/.local/bin/uvx
```

对于旧版本（`v0.5.2` 之前）：

```js
rm ~/.cargo/bin/uv
rm ~/.cargo/bin/uvx
```

提示‌：如果不确定位置，可以运行 `which uv` 查看具体路径，然后删除该文件。

#### 2. 清理缓存、数据和配置目录

为了彻底释放空间并移除由 `uv` 下载的 `Python` 解释器，请删除以下目录：

```js
// 删除缓存文件（下载的 wheels、构建产物等）
rm -rf ~/.cache/uv

// 删除数据目录（包括 uv 管理的 Python 版本和工具）
rm -rf ~/.local/share/uv

// 删除配置文件（如果有自定义配置）
rm -rf ~/.config/uv
```

#### 3. 清理环境变量（可选但推荐）

检查你的 `Shell` 配置文件（如 `~/.zshrc`、`~/.bash_profile` 或 `~/.profile`），看是否包含类似以下的行：

```js
export PATH="$HOME/.local/bin:$PATH"
// 或
export PATH="$HOME/.cargo/bin:$PATH"
```

如果这些路径仅用于 `uv` 且你不再需要它们，可以删除或注释掉这些行，然后运行 `source ~/.zshrc`（或对应的配置文件）使更改生效。如果其他工具也使用这些路径，请保留该行。

#### 4. 验证卸载是否成功

完成上述步骤后，关闭并重新打开终端，运行以下命令进行验证：

```js
uv --version
which uv
```

如果系统返回 `command not found: uv` 或 `which uv` 无输出，则说明 `uv` 已成功卸载。

##### 4-1 注意事项

1. `‌pip uninstall uv` 无效‌：如果你是通过官方脚本安装的独立二进制文件，`pip uninstall uv` ‌不会‌卸载它，因为二者是完全独立的安装方式。只有当你通过 `pip install uv` 将 `uv` 作为 `Python` 包安装时，才使用 `pip` 卸载。

2. ‌虚拟环境不受影响‌：卸载 `uv` 工具本身不会删除你项目中已创建的 `.venv` 虚拟环境。如果你希望清理项目中的虚拟环境，需要手动删除项目目录下的 `.venv` 文件夹。
