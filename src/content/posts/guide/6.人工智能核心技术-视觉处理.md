## 人工智能第六章 课程练习题（含答案解析）

### 一、单选题

**1.** 计算机视觉（CV）中，C 和 V 分别代表什么？

- A. Computer 和 Video
- B. Computer 和 Vision
- C. Camera 和 Vision
- D. Cloud 和 Visual

**答案：** B

**解析：** CV 即 Computer Vision，C 代表 Computer（计算机），V 代表 Vision（视觉），合起来就是计算机视觉。

**2.** 计算机视觉属于人工智能中哪个范畴？

- A. 认知智能
- B. 决策智能
- C. 感知智能
- D. 运动智能

**答案：** C

**解析：** 计算机视觉属于人工智能中感知智能的范畴，是让机器具备视觉感知能力的一种技术。

**3.** 根据课程内容，人类获取信息中有多大比例来自于视觉？

- A. 50%以上
- B. 60%以上
- C. 70%以上
- D. 80%以上

**答案：** D

**解析：** 课程中明确提到，人类获取信息 80%以上都来自于视觉，这体现了视觉在信息获取中的重要性。

**4.** 在计算机视觉的基本流程中，"去除图像中的噪声、增强图像质量"属于哪个步骤？

- A. 图像采集
- B. 预处理
- C. 特征提取
- D. 分析识别

**答案：** B

**解析：** 预处理步骤负责去除图像中的噪声、增强图像质量等，相当于眼睛对光线进行初步的调节和过滤。

**5.** CNN（卷积神经网络）中，负责对特征进行压缩、减少数据量但保留重要特征信息的层是？

- A. 卷积层
- B. 池化层
- C. 全连接层
- D. 输入层

**答案：** B

**解析：** 池化层（Pooling Layer）对特征进行压缩，减少数据量，但能够保留重要的特征信息。卷积层负责提取图像特征，全连接层负责整合分类。

**6.** YOLO 算法的英文全称是什么？

- A. You Only Learn Once
- B. You Only Look Once
- C. Your Object Location Optimizer
- D. Yield Object Label Output

**答案：** B

**解析：** YOLO 是 You Only Look Once 的缩写，意为"你只需要看一次"，它将目标检测看作一个简单的回归问题，速度非常快。

**7.** 在目标检测中，用于确定目标位置的矩形框称为？

- A. 候选框
- B. 边界框（Bounding Box）
- C. 锚框
- D. 感兴趣区域

**答案：** B

**解析：** 目标检测中通常使用边界框（Bounding Box）来框住目标对象，表示其位置和大小。算法会先确定候选区域，再通过分类器判断并计算精确的边界框。

**8.** 语义分割与实例分割的主要区别是什么？

- A. 语义分割只分类不定位，实例分割既分类又定位
- B. 语义分割进行像素级分类，实例分割在此基础上还能区分同类别的不同个体
- C. 语义分割用于医疗，实例分割用于自动驾驶
- D. 语义分割用 CNN，实例分割用 RNN

**答案：** B

**解析：** 语义分割进行像素级别的分类，而实例分割在语义分割的基础上更进一步，能够区分出同一类别的不同个体实例。例如不仅能区分出车辆，还能区分出每辆不同的车。

**9.** 以下哪个模型专门用于实例分割？

- A. FCN
- B. Mask R-CNN
- C. YOLO
- D. Fast R-CNN

**答案：** B

**解析：** Mask R-CNN 是在 Fast R-CNN 基础上增加了一个 Mask 分支，能够实现对每个实例的精确分割，是实例分割的出色模型。FCN 主要用于语义分割。

**10.** 人脸识别中，"活体检测"的主要作用是什么？

- A. 检测人脸是否漂亮
- B. 检测当前是否为活人本人，防止用照片或视频冒充
- C. 检测人脸的健康状况
- D. 检测人脸的表情变化

**答案：** B

**解析：** 活体检测用于判断当前进行验证的是否是活人本人，防止有人利用照片或预先录制的视频来伪造、冒充他人进行身份验证。常见方式包括让用户做随机动作如眨眼、张嘴、摇头等。

**11.** OCR 文字识别的预处理阶段不包括以下哪项？

- A. 图像增强
- B. 二值化
- C. 降噪
- D. 字符识别

**答案：** D

**解析：** OCR 预处理阶段包括图像增强（提高对比度）、二值化（转为黑白图像）、降噪和倾斜矫正。字符识别是预处理之后的独立步骤，不属于预处理阶段。

**12.** 在 OCR 中，将彩色或灰度图像转化为黑白二值图像的技术称为？

- A. 图像增强
- B. 二值化
- C. 降噪
- D. 倾斜矫正

**答案：** B

**解析：** 二值化是将彩色或灰度图像转化为黑白二值图像的技术，以便后续处理。这是 OCR 预处理的重要步骤之一。

**13.** 机器视觉与计算机视觉在应用领域上的主要区别是？

- A. 机器视觉用于医疗，计算机视觉用于工业
- B. 计算机视觉主要应用于生活场景，机器视觉用于工业产品领域
- C. 两者应用领域完全相同
- D. 机器视觉用于室外，计算机视觉用于室内

**答案：** B

**解析：** 计算机视觉主要应用于生活场景，如人脸识别（门禁、安防）、图像分类（手机相册）等；机器视觉用于工业产品领域，如电子元器件检测、机械零件检测等。

**14.** 机器视觉在技术要求上相比计算机视觉更强调什么？

- A. 美观性
- B. 实时性、高精度和高速度
- C. 低成本
- D. 便携性

**答案：** B

**解析：** 机器视觉更强调实时性、高精度和高速度。在工业生产线上，产品源源不断地流动，机器视觉系统必须在极短时间内做出高精度的判断和检测。

**15.** 在 Python 代码中调用百度 OCR 时，使用中文引号或中文标点会导致什么问题？

- A. 没有影响，正常运行
- B. 程序运行变慢
- C. 代码报错，因为中文标点占两个字节，与英文标点完全不同
- D. 只影响显示不影响运行

**答案：** C

**解析：** 中文引号和标点占两个字节，而英文引号只占一个字节，在电脑看来是完全不同的字符。使用中文标点会导致代码语法错误，必须使用英文标点。

**16.** 在驾驶检测领域，人体分析技术主要通过什么方式检测疲劳驾驶？

- A. 检测车速变化
- B. 通过车内摄像头检测驾驶员频繁打哈欠、闭眼时间过长等行为
- C. 检测方向盘转动频率
- D. 检测车辆行驶轨迹

**答案：** B

**解析：** 人体分析技术通过车内摄像头和传感器检测驾驶员状态，如频繁打哈欠、闭眼睛时间过长等疲劳或分心行为，并发出警告提醒驾驶员休息。

**17.** FCN（全卷积网络）在图像分割中的主要特点是什么？

- A. 只能处理固定大小的图像
- B. 将传统卷积神经网络中的全连接层全部换成卷积层，实现像素级别的分割
- C. 只能进行目标检测不能进行分割
- D. 使用循环神经网络结构

**答案：** B

**解析：** FCN 将传统卷积神经网络中的全连接层全部换成卷积层，这样对图像分割时是像素级别的，输出的每个像素都有所属的类别。

### 三、简答题

**1.** 简述计算机视觉的定义及其在人工智能中的定位。

**参考答案：** 计算机视觉（Computer Vision，CV）简单来说就是让计算机能够像人类一样，看懂摄像头拍摄的图像和视频的信息。它属于人工智能中感知智能的范畴，是让机器具备视觉的一种技术。计算机视觉通过摄像头采集图像（相当于人眼接收光线），然后通过各种算法和模型对采集的图像进行分析和理解（相当于大脑处理信号），从而实现图像识别、目标检测等功能。

**2.** 简述 CNN（卷积神经网络）的关键组成部分及各自的作用。

**参考答案：** CNN 是深度学习中专门用于处理图像的强大工具，其关键组成部分包括：（1）卷积层：负责提取丰富多彩的图像特征，如物体的形状、颜色、纹理等；（2）池化层：对特征进行压缩，减少数据量，但同时能够保留重要的特征信息；（3）全连接层：根据前面两层提取的特征信息进行整合分类，通过模仿人类大脑处理视觉信号的方式，最终分析得到分类结果。
